MOLECULE DISCOVERY ✦ MD-by-AI · Inverse Design
Search History
Describe the material you want

This feature calls a separate inverse-design model ("MD-by-AI", a teammate's CVAE) that's still an early prototype. Three known limitations affect result quality, confirmed by reading its source directly:

  • Small training set — the model was trained on 37 hand-picked molecules, not nearly enough to learn general chemistry or generalize to new requests.
  • Property mismatch — the properties you enter (energy gap, dipole moment, hardness, etc.) aren't the properties the model was actually trained to condition on internally, so generation isn't well steered by your specific request yet.
  • Fallback padding — when the model can't generate enough valid, unique molecules on its own, it pads the result list with a fixed pool of generic building blocks (benzene, phenol, thiophene, pyrimidine, aniline, benzonitrile). AMAZEBOT flags these below whenever detected, so they're not mistaken for optimized results.

None of this is fixable from AMAZEBOT's side — it lives in the separate MD-by-AI model/repo. Results are shown for review, not as verified predictions.
